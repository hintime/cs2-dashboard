🔖 安装书签 · 一键导入库存

不需要任何扩展，添加一个浏览器书签即可。以后每次 2 秒完成。

📋 复制代码 → 新建书签

点下面按钮复制代码，然后按提示添加书签：

javascript:(function(){var u=location.href;if(!u.includes("steamcommunity.com")){alert("❌ 必须在 Steam 库存JSON页面使用\n\n当前页面："+u+"\n\n正确操作：\n① 打开 steamcommunity.com/my/inventory/json/730/2\n② 等页面加载完\n③ 再点这个书签");return}var t=document.body.textContent.trim();if(!t||t.length<10){alert("⚙ 页面内容为空 — 请确认 Steam++ 开着能访问社区");return}if(!t.startsWith("{")&&!t.startsWith("[")){alert("⚙ 页面不是JSON格式 — 确认你是不是在 JSON 页面上（URL以 /730/2 结尾）\n\n页面开头："+t.slice(0,80));return}try{var d=JSON.parse(t);if(!d.assets||!d.success){alert("⚙ 库存数据异常 — 可能库存未公开或 Steam 返回了其他响应");return}window.name=t;window.location="https://cs2wyx.asia/?auto_import=1"}catch(e){if(navigator.clipboard){navigator.clipboard.writeText(t).then(function(){alert("⚠ 自动导入失败，但JSON已复制到剪贴板\n\n请手动切换到看板 → Ctrl+V 粘贴 → 导入")})}else{alert("⚠ 解析失败，请手动 Ctrl+A 全选 → Ctrl+C 复制 → 到看板粘贴导入")}}})();

👇 复制后，按下面步骤操作：

1 打开书签管理器

按 Ctrl+Shift+O（Chrome/Edge 通用）

2 新建书签

点「添加新书签」或「新建书签」

3 粘贴代码

名称填 CS2 导入，网址栏 Ctrl+V → 保存到书签栏

📖 使用方式

⚠ 重要：书签只能在 steamcommunity.com 上用

  1. 开 Steam++，浏览器新开标签页，输入： steamcommunity.com/my/inventory/json/730/2
  2. 看到满屏 JSON 后，点到书签栏 → 点一下刚装的那个书签
  3. 自动跳转到看板，库存已自动导入 ✅
⚠ 注意：书签只能在你自己的电脑上用。
如果弹出"必须在 Steam 库存JSON页面使用"——说明你点书签的时候不在那页面上。
